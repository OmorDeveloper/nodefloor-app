# Pricing and licensing

A licence caps **how many nodes run at once**. That is the only thing it
changes: no feature is held back, no tab is locked, and nothing is watermarked.

## Core counts as a node

Core is the orchestrator. He sits at a desk, spends tokens and does work, so he
counts against the limit like anything else on the floor.

So **"3 nodes" means Core plus two you hire.** Excluding him would mean the free
tier really ran four agents and every paid tier one more than it sold, which is
not a number anyone could plan around.

| Tier | Price | Nodes at once |
|---|---|---|
| **Free** | free | 3 — Core plus two |
| **Six** | $599 / year | 6 — Core plus five |
| **Nine** | $999 / year | 9 — Core plus eight |
| **Unlimited** | $3,999 / year | as many as the machine will run |
| **The source** | $9,999 once | not a licence — see below |

## The free tier

Not a trial. It does not expire, nothing is feature-gated, and using it for paid
client work is fine. If three nodes is enough for how you work, that is a
complete answer and you never need to pay.

## What a licence covers

- Every machine **you personally** run NodeFloor on. It is per person, not per
  device — a desktop and a laptop are one licence.
- A year from the day it is issued.
- Direct support from the person who wrote it.

## What happens when a licence lapses

Your work stays yours. Everything you have made still opens, your memory files
and workflows are untouched, and the app keeps running — the node limit simply
drops back to the free tier's three.

Nothing is deleted, held hostage, or converted to read-only. A lapsed licence
should cost you capacity, not your work.
